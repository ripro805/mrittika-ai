# Acknowledgements & Data Sources

Mrittika AI builds upon the dedication of the open-source software, machine learning, and agricultural research communities.

---

## 1. Machine Learning Artifacts & Dataset
- **Hugging Face Repository**: `ripro805/mrittika-ai`
  - Host of the serialized model artifacts: `mrittika_crop_model.pkl` and `mrittika_fertilizer_model.pkl`.
  - Benchmark datasets: `bangladesh_crop_recommendation.csv` and `bangladesh_fertilizer_recommendation.csv`.

---

## 2. Agricultural Institutions & Guidelines
- **Bangladesh Agricultural Research Council (BARC)**: For the standard principles underlying the Fertilizer Recommendation Guide (FRG).
- **Bangladesh Rice Research Institute (BRRI)**: For Rice Knowledge Bank and seasonal rice management practices (Aman, Aus, Boro).
- **Bangladesh Agricultural Research Institute (BARI)**: For horticulture and winter crop advisory methodologies.
- **Department of Agricultural Extension (DAE)**: For extension officer workflows and upazila-level farmer support structures.

## 4. Open Source Libraries & APIs
- **Groq Cloud**: For ultra-fast, OpenAI-compatible LPU inference providing free-tier LLM generation (`openai/gpt-oss-120b`).
- **Google AI Studio / Gemini API**: For generous free-tier multimodal and multilingual language models (`gemini-2.5-flash-lite`).
- **Open-Meteo**: For accessible, high-resolution open-source weather forecasting and solar radiation APIs.
- **ChromaDB**: For vector embeddings storage and similarity search.
- **Sentence Transformers / Hugging Face**: For multilingual embedding models (`intfloat/multilingual-e5-large`, `paraphrase-multilingual-MiniLM-L12-v2`).
- **Scikit-learn, XGBoost & LightGBM**: For ensemble classification and multi-output regression pipelines.
- **Django & Django REST Framework**: For secure, rock-solid web API backends.
- **React, Vite, Tailwind CSS & Lucide Icons**: For responsive, accessible, mobile-first user interfaces.
